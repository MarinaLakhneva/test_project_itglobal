## SimpleOne
### Тестовое задание

Стек: HTML, CSS(препроцессор SCSS), JS, React.js 


Макет: https://www.figma.com/design/BYYUK0ZtyQx8CfDf7SBXpU/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D0%BE%D0%B5-%D0%B2%D1%91%D1%80%D1%81%D1%82%D0%BA%D0%B8?node-id=0-1&t=ttUmzRURYjwGBrnv-1


Процесс работы:
1. Анализ макета, выделение переиспользуемых частей, чтобы вынести их в компоненты.
2. Верстка header.
3. Верстка content-части и добавление функциональности.
4. Закрепление шапки и навигации.
5. Добавление адаптива.

Assets и mock расположены рядом с файлом, в котором они используются, в большом проекте нужно вынести в отдельную папку.

Функционал:
1. "+" - кнопка добавления value дизайна. В случае добавления value в поля: "Ответственный", "Группа", "Кем открыто", "Кем создано" меняется background-color и кнопка становится disabled.
2. Календарь работает, выбрать дату можно нажав на кнопочку справа.
3. Поиск не реализован.
